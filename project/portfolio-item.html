Portfolio

Portfolio gemaat met HTML CSS in bootstrap

Volledige beschrijving

Dit portfolio is volledig door mij ontworpen en gebouwd met HTML5, CSS, Bootstrap en een vleugje JavaScript voor interactieve elementen. De layout is responsief opgebouwd zodat alle pagina’s — van de projectoverzichten tot mijn persoonlijke info — op elk schermformaat strak en overzichtelijk blijven.

Het portfolio bevat een duidelijke navigatie naar al mijn projecten, waarbij elke projectpagina zelfstandig is opgebouwd met eigen structuur, beschrijving en visuals. Daarnaast heb ik een aparte contactpagina toegevoegd, voorzien van een simpel maar functioneel formulier dat bezoekers makkelijk met mij laat opnemen.

In de over-mij sectie geef ik een helder beeld van mijn achtergrond: mijn ervaringen, wat ik heb gestudeerd en welke vaardigheden ik gebruik in mijn werk. De combinatie van semantische HTML, maatwerk CSS, Bootstrap-componenten en wat JavaScript zorgt ervoor dat het hele portfolio snel, clean en prettig te gebruiken is. Dit project laat zien dat ik niet alleen losse webpagina’s kan maken, maar een complete, goed opgebouwde website kan neerzetten.
